# 设置导航与手势目标库设计

## 目标

将不断增长的首页重构为场景化一级入口，并用统一批量勾选器管理底角扇形、底角二段蜂窝和侧滑三套独立清单。

## 一级菜单

首页只显示版本、Hook 接口状态和七个统一卡片：

1. 启用手势：总开关直接显示；二级页包含全局震动、选中名称和接口状态。
2. 底角斜滑：触发范围、第一段扇形及其呼出动效。
3. 侧滑手势：方向、阈值、布局、应用来源和启动方式。
4. 蜂窝应用与动效：二段蜂窝应用、圆盘尺寸、操作模式、背景与动画参数。
5. 小窗位置设置：小窗预览、宽高和水平/垂直位置。
6. 窗外点击设置：单击、双击及行为说明。
7. 杂项设置：同时热重载 SystemUI 和小米桌面、恢复默认、版本与诊断信息。

首页不再直接放置应用列表、滑条、小窗预览或动画参数。原独立“动画效果”入口取消，参数回归各自手势场景。

## 目标清单

- 底角扇形：应用、双开应用和快捷方式，上限可设为 3–24，默认 8。
- 底角二段蜂窝：只包含普通应用和双开应用，上限可设为 1–60，默认 36。
- 侧滑应用：只包含普通应用和双开应用，上限可设为 1–36，默认 12。

侧滑默认“实时跟随二段蜂窝清单”。关闭跟随后可独立编辑，并提供“复制当前二段蜂窝清单”的一次性操作。同步源不是底角第一段扇形。

## 批量勾选器

- 调用方传入清单类型、已选目标、数量上限和是否允许快捷方式。
- 当前已选项进入时自动勾选。
- 支持搜索、当前搜索结果全选、反选和清空。
- 顶部实时显示已选数量和上限；达到上限后停止新增并提示。
- 点击“完成”才一次性返回新清单；系统返回放弃未保存变更。
- 扇形的“批量选择应用”和“批量选择快捷方式”只替换同类目标，保留另一类及其顺序。

## 迁移与验证

- 现有扇形目标原样迁移，不因新上限丢失。
- 当前蜂窝目标迁移为二段蜂窝清单。
- 批量勾选、取消、搜索操作、上限和 JSON 往返要有自动测试。
- 三套清单的实时跟随、一次复制和独立编辑进行实机验证。
