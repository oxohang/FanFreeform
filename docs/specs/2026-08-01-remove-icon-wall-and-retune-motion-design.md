# 回退图标墙与重新调整动效设计

## 目标

回退 build132 中不符合使用预期的三列图标墙和设置页矢量图标，修正底角触发震动，并让蜂窝打开应用与任务中心整体动画具备明确可调的速度。

## 功能变更

### 删除三列图标墙

- 从侧滑布局和任务中心布局中删除三列图标墙选项。
- 删除共享图标墙几何、绘制、命中、自动滚动和相关测试。
- 兼容已保存配置：侧滑图标墙自动回退为纵向列表，任务中心图标墙自动回退为横向图标。
- 保留之前已修复的任务中心增量选择逻辑，不恢复边缘“拖动债务”问题。

### 删除设置页矢量图标

- 首页和手势设置入口恢复纯文字卡片。
- 删除 build132 新增的五个 `ic_setting_*` 矢量资源和引用。
- 不改动应用图标、启动图标或系统自带图标。

### 底角斜滑震动

- “底角上滑触发震动”只控制手势越过一段呼出阈值的单次震动。
- 开启时，每次有效底角手势越过阈值震动一次；关闭时该震动完全不触发。
- 全局“震动反馈”仍是总开关：总开关关闭时所有震动停止；总开关开启时，本开关独立决定底角触发震动。
- 应用图标之间的选择震动仍由全局“震动反馈”开关控制，两个开关职责不重叠。
- 呼出判定保持只执行一次，避免同一手势重复震动。

### 蜂窝全屏启动动画速度

- 设置项改为“全屏启动动画速度”，不通过延迟发起应用来制造慢速感。
- 保留五档设置：很快、较快、标准、柔和、慢速，对应全屏窗口展开时长约 `180 / 260 / 360 / 500 / 680ms`。
- 仅在底角蜂窝或侧滑蜂窝以全屏模式打开应用时使用；小窗启动保持 HyperOS 原有动画。
- 蜂窝呼出、拖动、惯性和选中收束仍由原“动画速度”控制，不受全屏启动档位影响。
- 全屏窗口使用从中心轻微缩放并淡入的自定义转场，已在前台的任务也尝试覆盖默认任务切换动画。
- 动画资源不可用时自动回退到当前中心缩放启动，不阻断应用打开。
- 默认使用标准档；复用 build132 新增配置的存储值，避免用户选择被重置。

### 任务中心动画

- 任务中心不再应用全局“选择旋转形变”，卡片和图标均保持正直。
- 全局旋转形变设置仍保留并继续作用于底角扇形、侧滑布局和蜂窝。
- 在任务中心动效页增加“整体动画速度”五档设置。
- 同一速度倍率统一作用于呼出、选中回弹、确认启动和取消关闭四段动画。
- 现有“横向跟手速度”继续独立控制手指移动与任务切换的映射，不被整体动画速度替代。
- 三种任务中心动效风格继续保留，新速度只缩放各风格的时间，不改变命中算法。

## 配置与迁移

- 新增任务中心整体动画速度配置，取值 `0..4`，默认为 `2`。
- 保留底角触发震动和 build132 新增速度配置的底层存储键，将后者的业务语义改为蜂窝全屏启动动画速度。
- 删除图标墙常量与运行时分支；读取到旧数值 `6` 或 `2` 时在 Provider 边界完成回退，不将无效值透传到 SystemUI。

## 安全性与性能

- 不恢复强制隐藏导航栏或覆盖层强制硬件层，保留 build132 的小横条和覆盖层释放修复。
- 保留小米桌面快捷方式目录后台刷新，不回退桌面进入卡顿修复。
- 速度调节仅在配置加载时解析倍率，绘制循环不增加持续对象分配。

## 验证

- 单元测试验证任务中心边缘拖动后仍能直接选择相邻应用。
- 验证旧图标墙配置的自动回退。
- 验证底角触发震动开启与关闭时的单次计数。
- 验证蜂窝全屏窗口转场和任务中心五档速度时长单调，且最慢档有明显差异。
- 验证蜂窝小窗启动不携带自定义全屏转场。
- 执行单元测试、Lint 和 debug APK 构建，版本号递增为 build133。
- 安装到已连接手机，核对已安装版本和 APK SHA-256；在权限允许时热重载 Hook 进程，不重启手机。
