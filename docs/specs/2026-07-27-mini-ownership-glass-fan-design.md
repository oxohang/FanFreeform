# 迷你窗任务归属与磨砂扇形界面设计

## 1. 目标

本轮同时解决两个功能缺陷并优化扇形界面：

1. “挂起”必须把当前普通小窗使用 HyperOS 原生动画缩小到右上角迷你窗，不能保留原尺寸后裁切。
2. 扇形打开的任务在迷你窗与普通小窗之间切换时必须保持模块归属；恢复普通小窗后，窗外单击和双击自动恢复，不能穿透操作下层应用。
3. 扇形界面采用轻量 HyperOS 磨砂玻璃风格，同时保持现有触发区域、扇形半径、图标大小设置、命中范围、应用顺序和手势仲裁不变。

## 2. 任务状态模型

`HyperOsFreeformBridge` 分离两个任务标识：

- `ownedTaskId`：由扇形启动且仍由模块负责的任务。普通小窗切换到迷你窗时保留。
- `trackedTaskId`：当前处于普通自由窗口、允许窗外操作的任务。进入迷你窗时暂时清空。

状态转换如下：

- 扇形成功打开普通小窗：`ownedTaskId` 与 `trackedTaskId` 同时指向该任务。
- 普通小窗挂起：保留 `ownedTaskId`，清空 `trackedTaskId`，暂停窗外拦截。
- 同一任务恢复普通小窗：任务回调识别 `ownedTaskId`，自动恢复 `trackedTaskId`。
- 关闭、全屏或任务消失：同时清除两个标识。
- 进入固定图标或未知非自由窗口模式：清除归属，避免接管不再符合条件的窗口。

待启动匹配仍以包名和时间窗为准。若目标包已有由模块持有的迷你任务，优先调用 HyperOS 原生迷你窗恢复接口，等待普通小窗回调后完成追踪，不重复创建任务。

## 3. 原生挂起与恢复

挂起操作在 WMShell 主执行器上调用当前 ROM 的 `MiuiFreeformModeController.fromFreeformToMini(taskId)`，由 HyperOS 计算迷你缩放、更新任务模式并执行手势动画。删除 `lunchSmallFreeformFromRecent` 路径，因为该接口用于最近任务入口，无法正确转换已显示的普通小窗。

右上角定位优先沿用 ROM 当前小窗到迷你窗动画；如果 ROM 根据当前窗口中心选择了左上角，只校正动画的迷你目标到对称的右上位置，不改变系统计算的缩放比例、纵向位置或动画类型。

恢复使用 `MiuiFreeformModeMiniStateHandler.restoreMiniToFreeformMode(taskId)`。接口不可用或调用失败时安全返回 `false` 并保留当前窗口，不使用会创建重复任务的降级路径。

## 4. 窗外输入规则

- 只有 `trackedTaskId` 指向可见普通小窗且实时边界有效时，才允许 `OutsideGestureRecognizer` 认领窗外触摸。
- 迷你状态不拦截窗外触摸，但仍保留 `ownedTaskId`。
- 恢复普通小窗的任务回调到达后，下一次触摸立即恢复窗外单击和双击。
- 左右系统返回手势保留区继续在窗外动作之前判定，不改变现有侧滑优先级。
- 关闭、全屏动作沿用已验证的 HyperOS 原生 Shell 执行器与原生动画入口。

## 5. 扇形视觉

视觉层继续使用单个轻量 `FanOverlayView`，不启用系统实时背景模糊，避免 SystemUI 覆盖层上的兼容性和性能风险。

- 背景：取消明显的全屏灰色遮罩，改为从触发角向外衰减的局部深色径向渐变。
- 轨道：两条静态圆环改为围绕图标的一条宽幅半透明玻璃圆弧，叠加细高光边缘。
- 图标：保持圆形内容填充；增加半透明玻璃底座、细白边和轻柔阴影。
- 选中态：图标平滑放大约 10%，沿径向向外浮起少量距离，显示系统蓝色柔光；其他图标适度降亮度。
- 名称：固定在选中图标的径向内侧，使用紧凑半透明圆角胶囊，限制最大宽度并省略过长名称，不再跟随手指坐标。
- 动画：呼出时整体在约 140ms 内淡入并从 94% 展开；选中变化使用约 90ms 平滑插值；隐藏保持约 90ms。
- 左右角完全镜像。视觉位移不参与命中测试，命中仍以原始图标中心和配置直径计算。

## 6. 失败处理与日志

- 反射接口缺失或 ROM 调用抛错时记录具体操作、任务 ID 与异常，恢复到安全空闲状态，不让 SystemUI 崩溃。
- 任务模式变化日志同时记录 owned/tracked 状态，便于区分“归属保留但交互暂停”和“归属已结束”。
- 覆盖层绘制不读取应用进程或执行阻塞操作；图标 drawable 在绘制后恢复原 bounds。

## 7. 验收标准

1. 扇形打开应用后，普通小窗的窗外单击关闭和双击全屏正常。
2. 执行挂起时，小窗以原生动画缩小到右上角，内容完整缩放，不出现原尺寸裁切。
3. 迷你状态点击桌面或下层应用不被模块拦截。
4. 点击迷你窗恢复普通小窗后，窗外操作自动恢复且不会穿透。
5. 从扇形再次选择已挂起的同一应用时恢复旧任务，不创建重复任务。
6. 左右侧滑返回继续优先，不被窗外单击识别器关闭小窗。
7. 扇形左右角视觉镜像正确，图标不拥挤，选中反馈清晰；空白处松手仍不启动应用。
8. 单元测试、lint、debug 构建通过，并在连接的 HyperOS 3 真机完成关键日志验证。
