# 第一版单圆弧扇形视觉修订

## 1. 定位

本规格取代 `2026-07-27-mini-ownership-glass-fan-design.md` 的第 5 节“扇形视觉”，不改变该规格中的任务归属、迷你窗挂起、恢复和窗外输入修复。

扇形界面恢复第一版的简洁结构，不再使用宽幅玻璃轨道、图标玻璃底座、非选中图标降亮和径向浮起效果。

## 2. 绘制结构

- 保留第一版从触发角向外渐隐的局部深蓝灰径向暗幕。
- 圆弧只绘制一条：保留第一版半径 `fanRadius - 64dp` 的内侧细圆弧；删除外侧圆弧。
- 图标继续沿原始 `fanRadius` 四分之一圆弧排列，保持圆形裁切并填满圆形区域。
- 不绘制连接图标的宽轨道，不在图标后增加玻璃圆盘。
- 应用名称继续位于手指上方并跟随手指，保持第一版紧凑深色胶囊。

## 3. 细节精修

- 内侧圆弧使用略低于第一版的白色透明度和约 `1.25dp` 线宽，避免抢夺图标注意力。
- 图标保留轻柔下投影与细白描边，降低描边不透明度，使不同应用图标看起来更统一。
- 选中图标维持约 `1.08x` 放大，蓝紫色选中环从 `4dp` 收细到约 `3dp`，缩小阴影范围。
- 覆盖层继续使用第一版快速整体淡入淡出，不增加逐图标展开或浮移动画。

## 4. 不变项

- 触发区、触发距离、选择半径、图标大小设置和应用顺序不变。
- 绘制中心与命中中心完全一致，空白处松手不启动应用。
- 左右触发角完全镜像。
- 功能层继续采用已确认的 `ownedTaskId` / `trackedTaskId` 状态模型和 HyperOS 原生迷你窗接口。

## 5. 验收标准

1. 界面整体观感与第一版一致，不出现宽幅玻璃轨道或图标玻璃底座。
2. 画面中只有一条内侧细圆弧，没有外侧圆弧。
3. 图标清晰、互不打架，选中反馈明显但不厚重。
4. 左右侧显示一致，命中逻辑和滑动手感不发生变化。
