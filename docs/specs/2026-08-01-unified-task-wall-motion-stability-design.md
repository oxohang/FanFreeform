# 任务图标墙、统一选择动效与稳定性设计

## 背景与目标

本版本将任务中心、侧滑应用列表、蜂窝应用和底角扇形的选择反馈收敛为一套稳定的交互规则，并在一个版本内完成以下目标：

- 任务中心增加可选的反向排列，只反转任务顺序，不反转触摸方向。
- 任务中心与侧滑应用列表各自新增“靠边图标墙”布局，并保留现有布局。
- 图标墙采用物理手指直接命中，只在上下边缘自动滚动，避免整个内容跟随横移而导致黏选。
- 优化任务中心和蜂窝的呼出、选中、确认与退出动效。
- 增加蜂窝启动确认动画速度、底角上滑震动、底角动画速度和全场景轻微旋转形变设置。
- 为设置首页和相关分区增加统一的 Android VectorDrawable 图标。
- 修复小米桌面初次进入时的卡顿、底部呼出蜂窝时的偶发 SystemUI 退出、以及无选择关闭覆盖层后小横条生硬弹出的界面跳动。

本版本不重写 HyperOS 小窗启动链路，不修改最近任务来源，不提高任务快照数量上限，不重启手机。

## 实现策略

采用“共享交互内核，场景独立绘制”的方案：

- 新增纯几何层，负责图标墙排列、左右镜像、反向序号映射、稳定命中和边缘自动滚动。
- 新增共享选择动效参数层，输出缩放、上浮、旋转、横纵形变与邻居让位系数。
- 任务中心、侧滑列表、蜂窝和底角扇形保留各自的数据源、窗口、绘制器和启动回调。
- 共享层不持有 `View`、`Drawable`、`Bitmap` 或 SystemUI 对象，便于纯 JVM 单元测试，也避免跨覆盖层泄漏。

不将所有覆盖层重写为一个超大 View，避免一次性改动 SystemUI 内的所有已验证链路。

## 稳定性与性能

### 小米桌面初次进入卡顿

当前 `ShortcutHostRuntime.install` 在小米桌面 `Application.attach` / `onCreate`
链路中同步执行快捷方式扫描、桌面数据库查询、图标解码和 Provider 上报。设置变更时的 ContentObserver 也在桌面主线程直接重复这一过程。

修复规则：

- `install` 只注册接收器和观察者，不在桌面主线程读取目录或解码图标。
- 使用单线程后台执行器刷新目录，一次只允许一个扫描任务。
- 连续设置通知在 `350ms` 窗口内合并；扫描进行中再来通知时只记录一次待刷新。
- 目录 JSON 未变时不重复上报；快捷图标按稳定版本标识增量更新。
- 每批 Binder 图标有严格数量和尺寸上限，批次之间可被新一代刷新取消。
- 记录扫描耗时、项目数和更新图标数，不记录快捷方式的私密标识或 URL。

### SystemUI 偶发退出

设备历史记录已确认 SystemUI 存在多次异常退出，部分退出前 PSS/RSS 约为 `400–626MB` / `598–707MB`。本版本不把没有堆栈的历史退出归因为单一原因，而是同时消除已确认的高风险生命周期和显存占用：

- 去掉任务中心和蜂窝全屏 View 的强制 `LAYER_TYPE_HARDWARE`，使用窗口默认硬件加速，不额外持有全屏缓存层。
- 所有覆盖层建立统一的关闭步骤：标记不可交互、取消待处理 move、动画、`Choreographer` 帧回调、延迟启动回调、惯性、壁纸回调，再移除窗口。
- 任务中心在关闭时统一释放快照引用；图标墙模式不请求任务快照。
- 蜂窝关闭后不得继续 `postInvalidateOnAnimation`，壁纸完成回调不得再强引用已关闭 View。
- 选择、绘制或单个图标失败时跳过当前项并记录精简错误；覆盖层级异常使用安全关闭，不将异常抛回 SystemUI 主循环。
- 保留壁纸降采样与有界缓存，清缓存时不回收仍被可见 View 持有的 Bitmap。

### 小横条与界面跳动

任务中心和蜂窝目前在覆盖层加入后主动设置沉浸式标志并调用 `WindowInsetsController.hide(navigationBars)`。覆盖层无选择退出后，系统会重新计算导航栏可见性，造成小横条突然弹出和底层应用跳动。

修复规则：

- 覆盖层不再主动显示或隐藏导航栏，也不修改系统栏行为。
- 使用全屏绘制与稳定的安全区几何共存；手势小横条的原有状态始终由底层应用和 SystemUI 管理。
- 无选择退出使用覆盖层自身的透明度和缩放退场，不触发系统栏切换。

## 靠边图标墙

### 布局

- 新布局名称为“靠边图标墙”。
- 使用三列紧凑错位圆形图标，中间列纵向偏移半个行间距，整体轮廓参考用户截图。
- 右侧呼出时图标墙靠右，左侧呼出时水平镜像并靠左。
- 图标中心、可见性、绘制顺序和命中均使用同一份预计算几何。
- 屏幕方向、屏幕高度、项目数或图标尺寸变化时重算几何；普通帧只读取数组，不每帧创建集合。
- 任务中心图标墙仅加载运行任务的应用图标，不加载快照；侧滑图标墙加载已配置的应用与快捷方式图标。
- 快捷方式继续绘制现有闪电角标。

### 选择与滚动

- 手指进入稳定图标命中圆时立即选中；两个相邻命中圆的交接区使用最近中心与小范围迟滞，超出所有项目的扩展交接半径后立即清除选中。
- 选中放大、旋转和邻居让位不改变命中圆，禁止被放大图标粘住手指。
- 横向移动只更新手指命中，不平移整面图标墙。
- 手指进入顶部或底部边缘带时，按进入深度产生连续纵向自动滚动；离开边缘带立即减速并停止。
- 自动滚动后继续以当前手指物理坐标重新命中，不锁定旧项。
- 选中项松手时启动；空白区松手时关闭，不启动任何项目。

### 任务反向排列

- 任务中心增加“任务排列方向：正常 / 反向”。
- 该设置适用于任务中心的卡片、横向图标和靠边图标墙，使三种布局的第一项语义一致。
- 反向只改变可见顺序到原始任务列表的索引映射。
- 物理手指命中、左右呼出方向、边缘滚动方向和松手启动规则不反转。
- 默认为正常，旧用户升级后行为不变。

## 统一动效模型

所有选择场景共用五个状态：

1. `ENTERING`：覆盖层淡入，项目从呼出边缘轻微位移、缩放并短暂错峰进入。
2. `TRACKING`：使用实际手指坐标更新选择，基础排列不被动效反向修改。
3. `SELECTED`：新项通过短弹性曲线获得放大、上浮、形变和邻居让位，旧项使用同一时间轴归位。
4. `CONFIRMING`：锁定已选索引，播放一次确认聚焦后调用现有启动链路。
5. `DISMISSING`：禁止新输入，快速但连续地降低位移、缩放与透明度，最后移除窗口。

动效计算使用一个场景时钟和每项纯函数，不为每个图标创建 `ValueAnimator`。只有状态未稳定、边缘自动滚动或惯性运行时请求下一帧。

### 轻微旋转形变

- 新增全局选择效果：关闭、轻微、标准、明显。
- 旧用户升级默认为“轻微”，可立即关闭。
- 图标旋转方向由当前手指水平速度和项目相对位置决定，速度为零时回正；三档最大角约为 `3° / 4.5° / 6°`。
- 横向与纵向缩放差限制在约 `2% / 3.5% / 5%`，只制造轻微弹性感。
- 任务卡片只应用约 `1° / 1.5° / 2°` 的整体倾斜，不独立扭曲快照内容。
- 效果仅修改 Canvas 变换与绘制参数，稳定命中区不变。

## 新增设置

### 任务中心

- 布局：横向卡片、横向图标、靠边图标墙。
- 任务排列：正常、反向。
- 图标墙预览：根据当前图标尺寸、间距和呼出侧绘制静态三列预览。
- 任务中心动效页保留苹果流畅、磁吸轨道和弹珠磁场，三者使用同一命中结果，只改变视觉参数。

### 侧滑应用列表

- 竖屏与横屏布局选项各自增加“靠边图标墙”。
- 保留现有纵向列表、环形、扇形、蜂窝等布局值及其迁移语义。
- 图标墙使用侧滑应用清单和当前全屏/小窗启动选项。

### 蜂窝应用

- 保留现有“动画速度”用于呼出、惯性与退场。
- 新增“启动确认速度”，范围为很快、较快、标准、柔和、慢速，默认为“标准”。
- 启动回调时间与确认动画时长使用同一映射，禁止画面还未聚焦就提前启动。

### 底角斜滑

- 新增“上滑触发震动”独立开关，仅管理底角从候选进入已接管/已显示状态的那一次震动。
- 该开关不覆盖选中项切换震动和确认震动，它们继续受现有全局震动开关管理。
- 新增底角独立动画速度，只影响底角扇形的呼出、选中和退出，不影响侧滑、蜂窝或任务中心。

### 全局选择效果

- 放入“启用手势”下的全局视觉/反馈分区，因为它同时影响底角、侧滑、蜂窝和任务中心。
- 选项为关闭、轻微、标准、明显。
- 任务中心三套原有动效作为基础运动曲线，全局形变叠加在最终绘制变换上，不改写原动效模式值。

## 设置页矢量图标

- 使用 Android `VectorDrawable` 资源，不增加字体图标、PNG 导航资源或第三方图标库。
- 图标统一为 `24dp` 视口、圆角线性语言和当前强调色。
- 覆盖底角斜滑、侧滑手势、蜂窝应用、任务中心、小窗位置、窗外点击、杂项、动效、布局和返回。
- 首页卡片左侧显示分区图标，右侧继续保留统一箭头；子页标题和重要分区可复用同一资源。
- 所有纯图标按钮设置内容描述和至少 `48dp` 触摸范围。

## 配置与兼容

- 新增图标墙布局值时只向后扩展枚举范围，不改变现有布局整数的语义。
- 任务反向默认关闭。
- 靠边图标墙不作为旧用户升级后的默认布局。
- 蜂窝启动确认速度默认为标准，底角动画速度从现有统一动画速度迁移。
- 底角上滑触发震动默认跟随现有全局震动值，升级时视觉/触感不突变。
- 全局轻微旋转形变默认为轻微，设置页可选关闭。
- Provider、`GestureConfig`、设置保存、分页恢复默认和全局恢复默认使用同一组默认值与范围。

## 验收与测试

### 自动测试

- 图标墙对 `1、2、3、7、10、19、36` 个项目生成稳定三列错位中心，左右镜像后顺序和边界正确。
- 任务反向索引对首项、末项、奇数和偶数任务数量正确，视觉选中的项目与实际启动对象一致。
- 稳定命中不受缩放、旋转、邻居让位和自动滚动的前一帧绘制位置影响。
- 边缘滚动在安全区内为零，进入边缘带后连续增长，到达内容上下界后为零。
- 现有“末项 → 首项 → 屏幕边缘 → 第二项”回归测试继续通过。
- 动效参数在输入速度、强度和进度边界下保持有限值，不输出 `NaN` 或无穷值。
- 新增配置的默认、范围、Provider 传输、分页重置与全局重置均有测试。
- 执行 `:app:testDebugUnitTest`、`:app:lintDebug` 和 `:app:assembleDebug`。

### 真机验收

- 任务中心三种布局在正常/反向下都能打开视觉选中的原任务。
- 靠边图标墙在左右侧、横竖屏、不同图标尺寸和数量下均可直接命中，不横向拖动整墙。
- 按住在上下边缘时平稳滚动，返回中部立即停止，不误启动。
- 在微信等前台应用连续呼出并空白关闭蜂窝和任务中心至少 `50` 次，手势小横条不生硬弹出，底层界面不跳动。
- 底角呼出蜂窝、连续切换选中和快速取消至少 `50` 次，SystemUI 不退出，不存在持续帧回调或显存逐次增长。
- 热重载小米桌面后验证首帧可交互，快捷方式目录在后台稍后完成，不阻塞桌面进入。
- 对比蜂窝启动确认的五档速度，确保画面聚焦与应用启动时机一致。
- 分别验证底角上滑震动开/关、底角独立动画速度和全场景四档旋转形变。
- 设置页矢量图标对齐、不裁切、深浅色背景可读，所有图标按钮具有内容描述。

## 发布

- 版本号从当前 `versionCode 131` 递增为 `132`，`versionName` 保持 `1.0`。
- 构建成功后将 Debug APK 独立归档到 `release-archive/`。
- 覆盖安装到已连接设备，核对已安装 `versionCode` 和 APK SHA-256。
- 使用项目已有的热重载链路重载 SystemUI 与小米桌面，不重启手机。
- 真机过程中若捕获到 SystemUI 异常退出，保留当次日志和退出信息，修复后重新完成稳定性计数。

## 非目标

- 不增加任务中心的上滑清理、任务锁定或分屏操作。
- 不修改 HyperOS 最近任务排序来源。
- 不将任务快照复制进靠边图标墙。
- 不修改小窗比例、位置、窗外点击和快捷方式启动语义。
- 不引入第三方 UI、动画或图标库。
