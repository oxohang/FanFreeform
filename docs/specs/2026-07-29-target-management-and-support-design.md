# 应用清单管理与支持入口设计

## 目标

整理底角斜滑、侧滑手势和蜂窝应用的目标选择入口，避免应用数量增加后把参数页面拉得过长；明确三类手势的数据边界，并在一级菜单加入不干扰设置操作的作者支持入口。

## 数据边界

- 底角斜滑扇形使用“小窗应用”清单，继续支持普通应用和快捷方式。
- 侧滑的纵向列表、环形列表和扇形列表共用同一套“侧滑应用”清单。切换布局只改变展示方式，不改变所选应用。
- 蜂窝使用独立的“蜂窝应用”清单，不读取侧滑清单，也不再作为侧滑列表的实时数据源。
- 蜂窝保持只选择普通应用；快捷方式仍归入底角小窗快捷目标。
- 三套清单继续保存为现有的 `components`、`side_components`、`honeycomb_components`，不引入重复配置键。

## 升级迁移

- 如果升级前侧滑启用了“跟随二段蜂窝应用”，首次进入新版本时把当时的蜂窝清单复制到侧滑独立清单。
- 复制完成后关闭旧同步状态并记录迁移标记，后续修改蜂窝清单不再影响侧滑。
- 如果侧滑已经存在独立清单，优先保留该清单，不用蜂窝数据覆盖。
- 旧“跟随二段蜂窝应用”和“复制二段蜂窝”控件从侧滑设置页移除，底层旧键仅用于一次性迁移兼容。

## 参数页入口

三个设置页采用一致的紧凑入口：

- 底角斜滑页显示“小窗应用”和“已选 N 项”。
- 侧滑手势页显示“侧滑应用”和“已选 N 项”。
- 蜂窝应用与动效页显示“蜂窝应用”和“已选 N 项”。
- 点击入口进入对应的独立管理页。
- 参数页不再直接展示批量选择按钮或完整目标列表；应用上限、布局、动效等参数仍保留在原设置页。
- 页面返回前台时重新读取数量，确保选择结果立即刷新。

## 独立管理页

- 使用一个可复用的目标管理 Activity，根据入口参数读取并保存对应清单。
- 顶部显示清单名称、已选数量和返回按钮。
- 主区域显示所有已选择项目；普通应用显示图标、名称和包名，快捷方式显示所属应用与“快捷方式”标识。
- 空清单显示明确空状态，并引导点击右下角悬浮添加按钮。
- 右下角使用圆形悬浮“＋”按钮，始终悬浮在列表上方。
- 每个已选项目支持移除；保留清单顺序，删除后其余项目顺次补位。

## 统一选择器

- 点击悬浮“＋”后进入现有选择器的多选模式，不在小弹窗中塞入完整应用列表。
- 小窗清单选择器顶部提供“应用 / 快捷方式”分段切换栏，并使用同一个保存动作。
- 侧滑与蜂窝清单选择器只展示普通应用。
- 默认使用复选框多选，右上角“保存”一次提交选择结果。
- 已勾选项目组成置顶分组，始终排列在未勾选项目之前；取消勾选后按应用名称回到普通列表位置。
- 置顶只影响选择器显示，不擅自改变已有清单的运行顺序；新勾选项目追加到现有清单末尾。
- 搜索时仍保持已勾选状态，清空搜索后恢复“已选置顶 + 未选名称排序”。
- 达到当前设置的数量上限后阻止新增勾选，并显示上限提示；取消已有项目不受限制。

## 一级菜单支持入口

- 一级菜单底部增加一张紧凑卡片，文案为：
  - 标题：“喜欢 Hyper手势？”
  - 说明：“如果它让你的操作更顺手，欢迎请开发者喝一杯 ☕”
- 点击卡片弹出大尺寸收款码视图，使用用户提供的微信收款码图片作为应用内资源。
- 弹层提供关闭按钮，点击弹层外也可关闭；二维码保持原始比例和足够清晰度。
- 首页不直接铺开二维码，避免挤占主要设置入口。

## 组件划分

- `TargetManagerActivity`：负责三类清单的展示、删除、悬浮添加入口和保存。
- `AppPickerActivity`：扩展为可按目标类型显示应用、快捷方式或二者，并负责已选置顶。
- `ConfigStore`：提供按清单类型读取、保存和一次性侧滑迁移的方法。
- `GestureSettingsActivity` 与 `HoneycombSettingsActivity`：只负责入口和数量摘要，不再承担目标列表渲染。
- `SupportQrDialog`：使用 Android `Dialog` 承载收款码图片、说明和关闭按钮，不向设置页面泄漏图片布局细节。

## 异常与兼容

- 快捷方式目录暂未读取完成时，小窗选择器保留刷新提示，不清空现有快捷方式选择。
- 应用被卸载或快捷方式失效时，管理页仍允许删除该条目；运行时继续沿用现有的无效目标过滤逻辑。
- 收款码资源读取失败时只隐藏图片并保留关闭操作，不影响首页其他设置。
- 所有配置更新继续通过现有 Provider 通知 SystemUI，目标清单保存后无需重启手机。

## 验证

- 分别修改三套清单，确认底角、侧滑三种布局和蜂窝读取正确且互不串联。
- 从旧“侧滑跟随蜂窝”配置升级，确认侧滑清单只迁移一次且不丢失。
- 在大量应用下验证已选项目即时置顶、取消后恢复排序、搜索状态和保存结果一致。
- 验证小窗管理页可以混合保存普通应用和快捷方式，侧滑与蜂窝不会出现快捷方式。
- 验证三个参数页只显示入口与正确数量，返回页面后数量立即刷新。
- 验证收款码清晰、可关闭、旋转屏幕或返回后不影响一级菜单。
- 联合验证手势选择细化规格中的蜂窝焦点增益、扇形多排容量和二段回拉边界，确保设置页整理没有改变运行时配置来源。
- 完整执行单元测试、Lint 和 Debug APK 构建，并独立归档新版本。
