# 蜂窝前台应用背景、布局编辑与小窗缩放预览设计

## 目标

修复“跟随系统原生尺寸”模式下调整“系统尺寸缩放”时小窗预览大小不变的问题。为蜂窝增加从当前前台 App 主题读取的背景纯色和可选实时界面模糊，并新增可视化蜂窝布局编辑器，允许通过拖动交换应用的实际蜂窝位置。

## 小窗缩放预览修复

- 小窗预览增加“原生尺寸模式”和“系统尺寸缩放百分比”输入。
- 未开启原生尺寸模式时，预览继续使用独立宽度、高度百分比。
- 开启原生尺寸模式时，以已保存的示意窗口宽高为 `100%` 基准，根据 `50..150%` 的系统尺寸缩放值实时改变预览窗口大小。
- 预览窗口放大后不得超过预览屏幕范围；超过时等比缩小至完整可见。
- 水平、垂直位置依据缩放后的预览窗口尺寸重新计算，滑条调整时实时更新。
- 竖屏、横屏预览分别使用各自的原生尺寸开关、缩放百分比和位置配置。
- 该修复仅改变设置页预览；真实小窗启动仍使用目标 App 的 HyperOS 原生边界和已有 `WindowSizePolicy`。
- 因目标 App 在设置页中未确定，预览只表示缩放大小和位置变化，不声称与每个 App 的原生长宽比完全一致。

## 蜂窝背景模式

### 设置

- 新增“使用当前 App 背景色”开关，默认开启。
- 新增“模糊当前界面”开关，默认关闭。
- 两个开关可同时开启：当前界面实时模糊，并叠加当前 App 背景色的低透明度色调。
- 仅开启背景色时，使用 App 背景纯色，不进行截屏或模糊。
- 仅开启界面模糊时，显示当前界面实时模糊并叠加背景压暗。
- 两个开关均关闭时，使用纯黑背景。
- 旧“使用纯黑背景”开关由上述两个开关取代。
- 蜂窝使用新的独立“界面模糊强度”数值，只在“模糊当前界面”开启时生效。
- 蜂窝使用新的独立“背景压暗”数值提高图标和文字可读性。

### 当前 App 背景色

- 在蜂窝显示前识别当前前台 Activity，读取该 Activity 主题的 `android:windowBackground`。
- 若 `windowBackground` 是纯色，直接使用该颜色。
- 若是图片、形状或其他 Drawable，将其绘制到小尺寸离屏位图并计算代表色，不截取用户当前屏幕内容。
- 缓存键由前台 Activity、App 版本更新时间和系统深色/浅色模式组成，同一 App 不重复取色。
- 读取 Activity 或主题失败时，根据当前系统深色/浅色模式使用安全默认背景色。
- 根据背景颜色亮度自动选择应用名称、提示文字、名称胶囊和图标衬底的明暗配色。

### 实时界面模糊

- 不截屏、不保存屏幕图像；优先使用 Android 窗口跨窗口背景模糊，让蜂窝覆盖层后的前台 App 由系统实时模糊。
- 模糊半径由现有模糊强度数值转换为屏幕像素，并夹到系统可用范围。
- 跨窗口模糊不可用、被 HyperOS 关闭或添加窗口参数失败时，不阻止蜂窝显示；若 App 背景色开关开启则回退到 App 背景纯色，否则回退到纯黑。
- 任务中心继续使用其现有壁纸模糊/纯黑背景逻辑，不读取蜂窝新增的两个开关。

## 蜂窝布局预览与编辑

### 入口与模式

- 在“蜂窝应用”设置页增加“蜂窝布局预览与编辑”入口。
- 新页面默认为预览模式，显示当前应用、快捷方式、图标大小、间距和实际蜂窝格子排列。
- 页面提供“编辑”按钮；进入编辑模式后才接受长按拖动，按钮改为“完成”。
- 预览自动等比适配当前屏幕可用区域，确保所有格子可见；不因预览缩放改变实际图标大小或间距配置。

### 拖动交换

- 编辑模式下长按任一图标后开始拖动，被拖图标放大并降低原格子透明度。
- 手指进入另一个有效蜂窝格子时，显示目标边框并给出一次轻震动。
- 在目标格子松手时，被拖应用与目标应用交换顺序；不支持自由坐标放置，不产生重叠图标。
- 在格子外松手时取消本次拖动，顺序不变。
- 每次成功交换后立即写入现有蜂窝应用清单，不新增另一份位置坐标数据。
- 运行时收到配置变化后使用新顺序，应用清单页和布局编辑页始终修改同一组数据。

### 共享几何

- 将“应用顺序到蜂窝格子”的纯几何计算抽取为 UI 和 SystemUI 运行时可共用的无 Android 状态工具。
- 布局编辑器和实际蜂窝均使用同一顺序、格子生成算法和索引映射，避免预览位置与真实位置不一致。
- 预览的唯一附加变换是为完整显示所有格子而施加的统一等比缩放和居中偏移。

## 配置与迁移

- 新增四个蜂窝独立配置：当前 App 背景色开关、当前界面模糊开关、界面模糊强度和背景压暗。
- 旧背景选择为纯黑时，首次迁移为两个新开关均关闭；旧背景选择为壁纸模糊时，首次迁移为 App 背景色开启、当前界面模糊关闭。
- 首次迁移时，蜂窝新的模糊强度和压暗数值分别复制当前旧值，保持视觉强度连续。
- 使用独立迁移标记，迁移只执行一次，之后不覆盖用户对新配置的选择。
- 旧背景选择、壁纸模糊强度和背景压暗键继续保留给任务中心使用，不由蜂窝新配置覆写。
- 蜂窝应用顺序不需要迁移；现有 JSON 数组顺序就是格子位置顺序。
- “恢复蜂窝布局默认值”同时恢复两个背景开关，不修改已选应用顺序；应用顺序仍只由应用清单页的“恢复默认”覆盖。

## 性能、隐私与回退

- App 背景色取色使用小尺寸离屏 Drawable 和有界缓存，不在每一帧重复计算。
- 背景色读取和非纯色 Drawable 取色不得阻塞 SystemUI 的手势主线程；未命中缓存时先使用安全默认色，异步结果返回后再更新背景。
- 实时界面模糊由系统窗口合成器完成，不生成、保存或传输用户屏幕截图。
- 布局编辑器的绘制不在 `onDraw` 中加载 App 信息或图标；所有图标在进入页面时预先解析。
- 任何前台 Activity 查询、主题资源、模糊参数或图标加载错误均记录诊断信息并回退，不阻止蜂窝呼出、选择和启动应用。

## 验证

- 验证原生尺寸模式下 `50% / 100% / 150%` 预览大小单调变化，且放大后不超出预览屏幕。
- 验证竖屏和横屏的缩放、水平位置和垂直位置分别生效。
- 验证 App 背景纯色、实时界面模糊、两者同开和两者同关的四种状态及回退路径。
- 验证浅色和深色背景均有可读的名称、胶囊和图标衬底配色。
- 验证前台 App 背景缓存命中、App 更新和夜间模式切换时的缓存失效。
- 验证共享几何对同一应用数量和间距生成与实际蜂窝相同的格子顺序。
- 验证拖动 `A` 到 `B` 后只交换两个索引，格子外松手不改变数据，并立即持久化。
- 验证快捷方式、双开应用和普通应用均显示正确图标并可交换。
- 运行单元测试、Lint 和 debug APK 构建，版本号递增。
- 安装到已连接手机，核对已安装版本和 APK SHA-256。
