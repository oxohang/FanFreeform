# 蜂窝全屏应用设计

## 目标

在现有“底角斜滑 → 扇形小窗快捷应用”手势后增加一段连续手势：手指越过扇形触发距离后继续向屏幕内滑，进入独立的 Apple Watch 风格蜂窝应用总览。蜂窝内的目标始终以普通全屏任务启动，不进入 HyperOS 小窗。

蜂窝是独立的用户自定义应用浏览界面，不是扇形菜单的另一种排版。它使用独立应用清单，最多 36 个普通应用或双开应用，不包含应用快捷方式。快捷方式继续属于现有小窗快捷目标。

## 体验原则

默认动效采用明显的中心层级、边缘收缩与短促弹性：效果明显但不慢，弹性强但不反复弹，缩放幅度大但触摸始终跟手。

- 二维自由浏览，不做成 Android 列表或应用抽屉。
- 所有空间形变随触摸位置连续计算，不在固定档位之间突变。
- 单次回弹即稳定，不做多次跳动。
- 优先保证触摸采样、布局位置和启动一致性；低帧率时先降低高成本视觉合成。

## 手势链路

1. 底角斜滑达到现有扇形阈值，照常显示小窗扇形。
2. 手指继续向屏幕内移动，超过独立“蜂窝触发距离”后，立即取消扇形当前选中，进入蜂窝过渡。
3. 扇形收拢淡出，蜂窝图标从当前触发底角扩散，两层最多重叠 120ms，不出现空白帧或突然换层。
4. 进入阈值默认依屏幕短边自动计算，约 170dp，可在 120–240dp 内调整。
5. 设置 16dp 回滞：进入蜂窝后，必须退回至“阈值 - 16dp”以内才取消蜂窝，防止临界位置反复切换。
6. 跨过蜂窝阈值时提供一次轻震动。

## 两种操作模式

### 浏览模式（默认）

- 蜂窝展开后可松手，界面保持。
- 单指拖动整个蜂窝画布，松手后使用短惯性减速。
- 支持以两指中心为锁点的双指缩放，默认范围 0.78–1.35。
- 点击图标执行聚焦动画并全屏启动应用。
- 点击空白关闭行为可在设置中开关。
- 系统返回始终关闭蜂窝。

### 按住滑选模式

- 用户全程保持按压，手指经过图标时进入选中状态。
- 图标切换提供轻震动，震动防抖 35–50ms。
- 松手时若选中图标，聚焦并全屏启动；未选中则执行取消动画。
- 不启用惯性和双指缩放，画布只做有限跟手移动。

两种模式使用独立触摸状态机，不仅是在同一逻辑中切换惯性或缩放开关。

## 蜂窝布局

蜂窝采用圆形密铺，不绘制六边形底板。设相邻圆心基础距离为 `P`：

- 同列纵向间距：`P`
- 相邻列横向间距：`P × 0.866`
- 奇数列纵向偏移：`P × 0.5`

默认基础图标直径为 52dp，圆心间距为 60dp，横向列间距约 52dp，奇偶列纵向错位 30dp，外围内容留白 72dp。用户清单顺序从初始视觉中心向外排布，少量应用自动形成紧凑居中布局。

## 动效参数

### 中心与边缘层级

- 视觉中心高于屏幕几何中心 30dp，减少手指遮挡。
- 中心最大缩放 1.28，中间区域约 0.90–1.10，边缘缩放 0.62。
- 中心透明度 1.0，边缘透明度 0.58。
- 边缘从屏幕短边的 30% 距离开始衰减，到 68% 距离时达到完全边缘效果。
- 距离映射使用 `smoothstep` 曲线，不使用线性放大镜效果。

### 呼出

- 默认总时长 280ms，图标初始缩放 0.35，初始透明度 0。
- 根据最终位置与触发底角的距离计算错峰，全部错峰压缩在 55ms 内。
- 到位时最大过冲 1.04–1.06，弹簧阻尼比约 0.72，仅回弹一次。
- 感觉顺序为：底角瞬间释放一组图标，向外扩散，轻微越过目标，单次回弹稳定。

### 选中与邻居让位

- 浏览模式按下缩放 1.16，滑选模式选中缩放 1.22。
- 最近邻沿“选中图标指向邻居”方向向外让位，最大 7dp；第二圈让位 2–3dp。
- 任意图标受多个影响后的累计让位不超过 8dp。
- 进入选中 90ms，离开恢复 110ms。

### 惯性与回弹

- 最小惯性速度 220dp/s，最大 5000dp/s，默认保留初始速度的 0.82。
- 默认减速度 3800dp/s²，最大越界 64dp，越界拖动系数 0.30。
- 回弹时长 220–260ms，阻尼比 0.78，过冲不超过 6dp。
- 惯性强度设置映射为低 0.65、中 0.82、高 1.00，默认为中。

### 确认并启动

- 聚焦总时长默认 230ms。
- 目标图标移至屏幕视觉中心，最终缩放 1.65。
- 其他图标在 100–130ms 内缩放至当前值的 0.86 并淡出。
- 动画开始后 145ms 发起普通全屏启动，启动请求发出后安全移除蜂窝层。
- 启动前若存在小窗，先关闭现有小窗并清理小窗窗外捕获层，再全屏启动目标。
- 只是进入后取消蜂窝时，原小窗保持不变。

### 取消

- 默认总时长 220ms，逆向错峰范围 40ms。
- 图标向当前触发底角收拢，最终缩放 0.25，透明度 0。
- 若手指仍按住且退回回滞阈值内，恢复扇形；若已抬手、返回或取消，则直接收回底角。

## 动画速度档位

不暴露毫秒值，提供五档速度并同步调整弹簧刚度：

| 档位 | 时间倍率 |
| --- | ---: |
| 很快 | 0.72 |
| 较快 | 0.86 |
| 标准 | 1.00 |
| 柔和 | 1.16 |
| 慢速 | 1.32 |

默认“标准”。

## 设置页

新增独立“蜂窝全屏应用”二级设置页，包含：

- 总开关。
- 蜂窝应用清单，最多 36 个，支持添加普通应用和双开应用、删除、拖动排序。
- 操作模式：浏览模式 / 按住滑选。
- 蜂窝触发距离：120–240dp，默认自动约 170dp。
- 基础图标大小和蜂窝圆心间距。
- 动画速度：很快 / 较快 / 标准 / 柔和 / 慢速。
- 惯性强度：低 / 中 / 高。
- 中心放大幅度、边缘缩小幅度、选中放大幅度。
- 点击空白关闭开关。
- “恢复 Apple 风格默认值”操作。

## 架构

### `HoneycombSettingsActivity`

管理蜂窝开关、独立应用清单、拖动排序和动效参数。应用选择器复用现有普通应用与双开应用目录，不显示快捷方式。

### `HoneycombOverlayController`

管理蜂窝全屏覆盖层的窗口层级、显示、暂停、恢复与移除。覆盖层低于状态栏和控制中心，高于普通应用。

### `HoneycombOverlayView`

只负责绘制、中心缩放、边缘衰减、邻居让位、惯性、回弹、双指缩放、呼出、选中、确认与取消动画。

### `HoneycombGeometry`

使用无 Android 界面依赖的纯函数计算圆形密铺坐标、紧凑中心排序、内容边界、中心距离缩放、命中和邻居让位。

### `HoneycombGestureState`

独立管理扇形到蜂窝的阈值与回滞，以及浏览模式和按住滑选模式的触摸状态。

### `FullscreenAppLauncher`

只负责启动普通全屏任务。主用户应用通过标准 `ActivityOptions` 启动；双开应用通过现有小米桌面跨用户入口启动。不调用 `HyperOsFreeformBridge.launch()`，不写入小窗任务跟踪，不创建窗外捕获。

## 小窗与系统界面协调

- 进入蜂窝时暂停现有小窗窗外捕获，但不立即关闭小窗。
- 取消蜂窝后，若原小窗仍存在，立即恢复窗外捕获。
- 确认蜂窝应用后，先关闭现有小窗，清理其窗外捕获和跟踪状态，再全屏启动蜂窝目标。
- 蜂窝层低于状态栏与控制中心，保留顶部系统下拉区域和系统返回。
- 通知栏或控制中心展开时，蜂窝暂停交互；收起后恢复。

## 异常处理

- 目标应用已卸载、禁用或双开入口失效：播放取消动画，显示“应用不可用”，不残留覆盖层。
- 应用较少：根据清单顺序从视觉中心向外生成紧凑布局。
- SystemUI 重载、显示尺寸变化、动画被系统取消：安全移除蜂窝覆盖层并清理手势状态。
- 系统“移除动画”开启：缩短动画时长，保留选中反馈和必要的状态切换。
- 任何启动失败路径都必须撤销蜂窝层和输入接管，不影响下层应用触摸。

## 验证

### 自动化验证

- 1–36 个应用的蜂窝坐标、六邻接关系和紧凑中心排序。
- 内容可拖动边界、越界阻尼、回弹目标、中心缩放与边缘透明度。
- 图标命中、选中转换、邻居让位与最大累计位移。
- 扇形阈值、蜂窝阈值、16dp 回滞和两种操作模式状态转移。
- 配置默认值、范围限制、应用清单 36 个上限与 JSON 往返。

### 实机验证

- 左右底角连续从扇形进入蜂窝，无误选、空白帧或遮罩残留。
- 浏览模式的拖动、惯性、越界、回弹、双指缩放、点击启动和返回关闭。
- 按住滑选模式的连续选中、震动防抖、松手启动和空白取消。
- 36 个图标同时显示时的帧率、图标缩放和拖动跟手性。
- 普通应用和双开应用均以全屏方式启动，不进入小窗。
- 存在小窗时：取消蜂窝保留小窗；确认应用先关闭小窗，再全屏启动。
- 顶部状态栏下拉、控制中心操作、系统返回与蜂窝层恢复。
- 应用不可用、SystemUI 重载和动画中断后不残留输入捕获。
