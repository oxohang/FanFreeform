# 蜂窝壁纸背景与连续物理动画设计

## 目标

保留明显的 Apple Watch 式中心放大、边缘压缩和邻居让位，将触摸、惯性、越界和回弹改为同一个连续二维物理系统，并以壁纸高斯模糊为默认背景。

## 连续物理

- 使用 `Choreographer` 帧回调和真实时间差积分位置、速度、摩擦、阻尼与弹簧。
- 拖动时位置直接跟随手指，不使用补间追赶。
- 松手时从最后数帧样本估算二维速度，连续进入摩擦减速。
- 越界后同一状态切换为弹簧恢复，不交给另一个动画器。
- 动画进行中重新按下立即从当前位置和速度接管。
- 双指缩放围绕两指焦点连续调整，不在抬手时跳动。
- 中心放大、边缘压缩、透明度和邻居让位每帧从当前坐标计算。

## 呼出锚点

- 提供“跟随手指 / 固定中心”单选，默认跟随手指。
- 跟随手指时，以跨过蜂窝阈值时的手指位置为初始中心，沿滑动方向向内偏移一个基础图标。
- 锚点被限制在状态栏与屏幕边界的安全区内。
- 浏览模式松手后保持该锚点，不自动跳回屏幕中心。

## 壁纸高斯背景

- 默认使用当前桌面壁纸快照，先降采样再执行 GPU 高斯模糊。
- 默认模糊半径 36dp，添加轻微暗层以保证图标可读性。
- 设置页提供背景风格（壁纸模糊 / 纯黑）、模糊强度和暗层强度。
- 壁纸读取失败时自动回退纯黑，不阻塞手势线程。
- 壁纸更换后下次呼出时更新缓存。

## 窗口层级

- 视觉层覆盖到屏幕底部，包括导航小横条。
- 顶部状态栏区域保持透明，状态栏内容与下拉手势始终可用。
- 视觉层与触摸层分离：高层级视觉层不接收触摸，交互层不覆盖顶部系统区域。
- 通知栏或控制中心开始下拉时立即移除高层级视觉层；收起后恢复蜂窝。

## 震动

- 所有扇形、侧滑和蜂窝选中震动只经过同一个 `HapticGate`。
- 全局震动关闭后，所有手势和选中震动立即停止。
- 只有选中索引真正改变时震动，默认防抖 55ms，同一图标的动画帧不会重复震动。

## 扇形多排

- 底角扇形超过当前半径可容纳数量时自动增加同心弧排。
- 每排容量根据实际弧长、图标大小和最小间距计算，外排容量可高于内排。
- 命中使用每个图标的实际中心，不再依赖单一角度索引。
- 呼出、选中、确认和取消动效同时适配所有弧排。

## 验证

- 物理积分、摩擦、弹簧、边界、重新接管和帧时间变化的纯函数测试。
- 跟手/固定锚点、左右底角和安全区夹取测试。
- 1–60 个蜂窝图标与 3–24 个多排扇形的布局与命中测试。
- 实机验证状态栏、控制中心、小横条覆盖、壁纸切换和长时拖动帧率。
