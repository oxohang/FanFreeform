# 统一手势选择动效设计

## 目标

- 底角扇形与侧滑列表采用相同的应用选择反馈。
- 经过应用时只做短促放大回弹，确认时做更明显的二次放大，不旋转图标。
- 侧滑列表入场与底角扇形一致：图标从手势方向轻微四散，依次到达最终位置。

## 实现

- 复用现有动画速度、呼出幅度和动画总开关。
- 选择阶段只改变图标缩放，不改变位置和旋转角度。
- 普通侧滑列表与侧滑扇形列表都记录入场起始时间，并按图标顺序执行短暂错峰动画。
- 关闭动画、小窗启动逻辑和手势判定保持不变。

## 验证

- 底角扇形、普通侧滑列表、侧滑扇形列表的选择反馈均为放大回弹。
- 三种布局确认应用时均有更明显放大反馈。
- 关闭动画、应用命中和未命中行为不发生回归。
- 单元测试、Android Lint 和 Debug 构建通过后热安装。
