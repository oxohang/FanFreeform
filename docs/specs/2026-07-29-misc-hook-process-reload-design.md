# 杂项设置与 Hook 进程热重载设计

## 目标

在杂项二级页提供一个固定“一键重载 Hook 进程”按钮，每次同时热重载 `com.android.systemui` 和 `com.miui.home`，不提供勾选，不重启手机。

## 行为

- 按钮标题为“一键重载 Hook 进程”。
- 点击后固定依次热重载 SystemUI 与小米桌面。
- 使用 root 权限，不调用 `reboot`、`setprop ctl.restart zygote` 或任何整机/框架重启路径。
- 进程结束后由 Android 系统自动拉起 SystemUI，再显式启动 HOME intent 恢复小米桌面。
- 按钮进入最多 5 秒冷却，防止连续触发；不弹出二次确认。
- root 拒绝或命令失败时只显示错误，不执行更大范围的回退重启。
- 进程恢复后通过现有配置 Provider 的接口时间验证 Hook 已重新连接，并在杂项页显示结果。

## 其他杂项

- 显示版本名、build 号、最后接口时间和当前 Hook 状态。
- 提供恢复所有参数默认值，但不删除用户的三套应用清单。
- 保留构建 APK 自动归档。

## 验证

- root 成功、root 拒绝、单个进程恢复超时三种路径。
- 验证按钮不会执行整机重启。
- 热重载后验证 SystemUI 手势、小米桌面快捷方式宿主和双开应用目录全部恢复。
